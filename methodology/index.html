Methodology

Separate evidence, calculation and opinion.

Financial guidance is more useful when users can tell which statements come from authoritative sources, which are deterministic calculations, and which are ShareCapsule planning judgments.

How a guide page is prepared

1. Define the user decision

Each page starts with a practical question such as controlling revolving credit, sizing liquidity, organizing expenses or choosing an investment category by time horizon.

2. Prefer primary authoritative sources

For U.S. household-finance topics, primary sources such as CFPB, SEC/Investor.gov, IRS, FDIC, HealthCare.gov and NAIC are preferred for rules, limits and official consumer guidance.

3. Distinguish official guidance from our heuristic

When ShareCapsule recommends an order of operations or planning threshold, it is labeled as “ShareCapsule opinion” rather than presented as a law, regulation or universal rule.

4. Avoid false precision

Targets such as emergency-fund months, spending percentages or portfolio mixes depend on household circumstances. The guide uses ranges and decision factors where a single number would be misleading.

5. Check time-sensitive values

Annual limits, tax thresholds, insurance limits and other changing values should include the applicable year and be rechecked against the current primary source.

6. Review for conflicts and missing context

Editorial review checks whether a recommendation could be inappropriate when debt costs, liquidity, taxes, insurance, time horizon or household obligations are considered together.

Planner recommendations

The private planner is designed to use transparent deterministic rules for its core recommendations. For example, it can flag a high-APR debt balance, a low emergency reserve or an expense-category trend based on values stored in the user’s local encrypted vault.

Where a calculation depends on assumptions, those assumptions should be visible. Where a decision requires facts the planner does not know, the output should say so rather than pretending certainty.

ShareCapsule opinion

The right goal is not to make the planner sound more confident. It is to make the reasoning inspectable enough that the user can understand why an action was suggested.
