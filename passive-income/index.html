How to use this page

Use an experiment mindset

Start with a small version that can reach a real user or customer. Track evidence—published assets, users, sales, repeat usage and maintenance time—rather than treating an idea as successful because it sounds attractive. When the first version is complete, continue logging results on the completed project and move the active focus to the next idea.
